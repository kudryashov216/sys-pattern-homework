⚙️ Режимы работы серверов

Сервер / Группа Режим записи (Write) Режим чтения (Read) Назначение
● DB_USERS_MASTER ✅ Да ❌ Нет (только для синхронизации) Приём регистраций, обновление профилей
● DB_USERS_SLAVE ❌ Нет ✅ Да (все запросы на профиль) Авторизация, отображение данных пользователя
● DB_BOOKS_SHARD_X_MASTER ✅ Да (новые книги, остатки) ❌ Нет Приём данных от поставщиков, обновление цен/остатков
● DB_BOOKS_SHARD_X_SLAVE ❌ Нет ✅ Да (каталог, поиск) Отдача каталога книг, поиск по названию/автору
● DB_STORES_MASTER ✅ Да ❌ Нет Обновление адресов, графиков работы
● DB_STORES_SLAVE ❌ Нет ✅ Да Показ информации о магазинах при оформлении заказа

🟡 Master — запись · 🔵 Slave — чтение
